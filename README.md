# Bachelors-thesis_scripts

Hello here you can find the Python scripts I have used for my bachelor's thesis 2026.

An explanation for the scripts you can find here:
detector_things.ipynb: The script used for observing detector patterns from every single simulation, including an averaged pattern between simulations and the detector RMSD calculations.

run_diffstructures.py: The script used to run simulations with the sampled structures. It is a .py file instead of a .ipynb file just so I could run it with nohup.

sulfur.ipynb: The script used to calculate the RMSD for the sulfur residues and the distance from the protein centre.

angles.ipynb: The main script used for angular RMSD calculations for the whole protein.
